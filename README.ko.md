# 앱스토어 · 플레이스토어 스크린샷 자동 제작 — 클로드 코드(Claude Code) 스킬 (ASO 등록 이미지)

**store-screenshots**는 [클로드 코드(Claude Code)](https://claude.com/claude-code) 스킬로, **App Store Connect**와 **Google Play Console** 등록용 스크린샷(앱 소개 이미지, 마케팅 스크린샷, ASO 크리에이티브)을 만드는 전 과정을 자동화합니다: 실기기/시뮬레이터 스테이징 캡처 → 헤드라인 카피가 들어간 코드 렌더 프레임 → 이중 QA 채점 게이트 → App Store Connect API / Play Developer API를 통한 자동 업로드.

앱 스토어 제출용 스크린샷을 매번 피그마·포토샵으로 손수 자르고 있었거나, `fastlane frameit`을 써봤지만 인라인 강조 텍스트가 안 돼서 막혔거나, **스크린샷이 실제 화면과 다르다는 이유·태블릿 레이아웃 불일치로 리젝**당한 경험이 있다면, 이 스킬이 그 작업 방식을 재현 가능한 코드 기반 파이프라인으로 대체해 줍니다.

**키워드:** 앱스토어 스크린샷, 플레이스토어 스크린샷, ASO, 앱스토어 최적화, 스크린샷 제작, 소개 이미지, App Store Connect API, Play Console API, 앱 마케팅, 앱 심사, 앱 리젝, 스토어 등록 이미지, 클로드 코드 스킬, AI 에이전트 스킬.

실제 출시 중인 iOS/Android 앱에서 품질 자가검토 루프를 여러 라운드 돌려(48점 → 91점) 확정한 절차입니다.

## 무엇을 하는가

- **실제 앱 상태를 스테이징**해서 캡처합니다 — 후보정으로 속이지 않습니다. 빈 데이터, 반토막 리스트, 엉뚱한 언어 텍스트가 스크린샷에 섞이는 일을 원천 차단합니다.
- **통합 테스트로 캡처를 자동화**합니다(폰·태블릿 시뮬레이터/에뮬레이터) — 앱 버전이 바뀔 때마다 재현 가능합니다.
- **프레임을 코드로 렌더링**합니다(헤드라인·서브카피·기기 목업), 픽셀 후처리는 0입니다 — 페이드·크롭·필러박스·디밴딩처럼 이음선을 만드는 편집을 하지 않습니다.
- **이중 QA 게이트**를 돕니다: 겹침·잘림·글자 깨짐·워터마크 같은 시각 결함 점검 + "스토어를 스크롤하는 유저가 3초 안에 다운로드할까?"에 앵커된 정량 채점.
- **API로 스토어에 직접 업로드**합니다(App Store Connect 스크린샷 세트 / Play Developer API 이미지 엔드포인트), 모든 자산이 정상 완료 상태에 도달했는지 확인까지 포함합니다.

## 사용법

```
~/.claude/skills/store-screenshots/SKILL.md
```

이후 "스토어 스크린샷 만들어줘" 같은 요청을 하면 클로드 코드가 자동으로 이 스킬을 적용합니다.
