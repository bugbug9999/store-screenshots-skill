# store-screenshots

A Claude Code skill: the standard pipeline for producing App Store / Play Store listing screenshots — staged real captures + code-rendered frames + a double QA gate + store upload via API. No pixel post-processing, no tablet compositing, no false claims.

Field-tested and refined over multiple quality-review rounds on a real shipping app.

- 🇰🇷 [SKILL.ko.md](./SKILL.ko.md) — original Korean version
- 🇺🇸 [SKILL.en.md](./SKILL.en.md) — English translation

## Usage

Drop `SKILL.ko.md` or `SKILL.en.md` into your Claude Code skills directory (e.g. `~/.claude/skills/store-screenshots/SKILL.md`) and rename to `SKILL.md`. Claude Code will pick it up automatically when you ask it to produce store screenshots.
